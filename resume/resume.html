OmitBench: Benchmark for Silent Omissions in Coding-Agent Patches2026

Python, AST analysis, mutation testing, LLM-as-judge evaluation, bootstrap CIs, GitHub Actions|github.com/Avnish1505/Omitbench|engineering blog

  • Built a labelled corpus by mutating merged commits from 8 Python libraries into three omission classes: 310 instances, 2,184 requirements per detector, 27.9% base rate, with a CI canary that fails if any detector sees the gold patch.
  • The headline result went against my thesis: the AST detector beats a no-AST grep baseline (ΔMCC +0.128) and a reasoning LLM judge (+0.111) but loses to a mid-tier judge, −0.202 (paired bootstrap CI excludes zero). MCC was pre-committed: flag-everything scores F1 0.44, MCC 0.000.
  • Swapping oracle requirements for LLM-extracted ones (a $0.06 run) dropped MCC from +0.499 to −0.935, which put the bottleneck in extraction, not detection. A pre-registered test of TypeSafe’s Jev judge found strong ranking (AUROC 0.936) but failed calibration (ECE 0.323).
  • Shipped the AST detector as a GitHub Action PR gate (p95 26.5 ms, 155 tests in CI) because it meets the 0.80 precision bar at 2.6× lower FPR than the winning judge; a gate that cries wolf gets switched off. Two detectors that missed a pre-agreed bar were retired.

Cancer Fusion AI: Multimodal Skin Lesion Classifier2026

PyTorch, timm, EfficientNetV2-S, ResNet50, conformal prediction, Grad-CAM, FastAPI, React|github.com/Avnish1505/cancer-fusion-ai|engineering blog

  • v1 fused ResNet50 features with age, sex and lesion site on HAM10000 (10,015 images, 7 classes, lesion-level split): 0.712 test macro-F1, but balanced accuracy fell from 0.722 to 0.653 on the official ISIC 2018 external test set.
  • Rebuilt as v2 (EfficientNetV2-S at 384 px, colour constancy, sqrt class weights, EMA, 8-view TTA): external balanced accuracy 0.782 (+0.129, paired CI [+0.088, +0.171]) with no external drop. Fusion beats image-only by +0.033, yet the form adds only +0.008 at inference.
  • Validation-fitted safety layer: malignant flag at 95% target sensitivity, conformal sets (91.5% coverage on ISIC 2018 at a 90% target), Mahalanobis OOD guard. v2 halves benign lesions flagged per cancer caught (1.72 to 0.86). Opt-in Grad-CAM cut CPU latency ~100 to ~31 ms.
